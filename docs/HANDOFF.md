# WORLD DESK — 인스타그램 릴스 경제 카드뉴스 (인수인계)

---

## 1. 프로젝트 개요

해외 **경제 뉴스**를 인스타그램 릴스용 세로 카드뉴스로 매일 제작한다.
채팅 세션에서 HTML 프리뷰 → Python(PIL) + ffmpeg 렌더 → MP4 파이프라인까지 구축 완료.

---

## 2. 확정 제작 규칙 (변경 금지 사항)

| 항목 | 규칙 |
|---|---|
| 해상도 | 1080 × 1920 (9:16) |
| 구성 | 뉴스 카드 5장 + 아웃트로 1장 = **6장** (인트로/표지 없음) |
| 길이 | 카드당 5초, 전환 크로스페이드 0.35초 → 총 28.3초 |
| 주제 | 해외 경제/시장 고정 |
| 카드 순서 | **가장 자극적인 기사를 1번**에 배치 (첫 3초 이탈 방어) |
| 디자인 | 전 카드 동일 템플릿 (색·폰트·레이아웃 통일) |
| 이미지 | 보도사진 사용 안 함. 뉴스 데이터를 직접 그린 SVG/PIL 그래픽 사용 |
| 안전영역 | 상단 160px, **하단 480px**, 우측 250px는 인스타 UI 영역 → 본문 배치 금지 |

### 저작권 관련 (중요)
사용자는 "개인 소장용이니 보도사진을 그대로 쓰자"고 요청했으나,
릴스는 업로드 시점에 공개 배포이므로 **로이터·AP·게티 등 보도사진은 복제하지 않는다.**
대신 사용자가 직접 정한 폴백 규칙(브랜드 그래픽 + 데이터 그래픽)으로 대체하기로 합의됨.
필요 시 Unsplash / Pexels / CC0 이미지는 사용 가능.

## 4. 카드 레이아웃 스펙 (1080×1920 절대좌표)

```
y=0    ┌──────────────────────────┐
       │  [상단 160px = 인스타 UI]  │  ← 그래픽만 흘림
y=172  │  ● CATEGORY      01 / 05 │  좌74 / 우74
y=236  │  ▮▮▬▬▬▬  진행바 5칸      │
       │                          │
       │      데이터 그래픽         │  0~880 full-bleed
y=602  │  LABEL                   │  mono 30px, 자간 6
y=640  │  132px 대형 수치          │  Noto Black
y=790  │  보조수치 34px            │
y=880  ├──────────────────────────┤  ← 그래픽 끝 (fade 300px)
y=910  │  헤드라인 76px / 행간 87   │  좌74, 폭 756 (우측 250 비움)
       │  요약 38px / 행간 57      │  최대 700px 폭 자동 줄바꿈
y=1384 │  ───────────────────     │
y=1400 │  날짜        SOURCE 출처  │
y=1440 ├──────────────────────────┤
       │  [하단 480px = 프로필·캡션] │  ← 비움
y=1920 └──────────────────────────┘
```

**애니메이션**
- 그래픽: 켄번스 줌 (배율 1.09→1.00, 카드마다 방향 교차)
- 상단 블록: 0~0.4초 페이드인
- 본문 블록: 0.3초 뒤 26px 아래→위 슬라이드 + 페이드인 (easeOutCubic)
- 카드 전환: xfade fade 0.35초

## 6. 렌더 파이프라인

### 환경 요구사항
- Python 3 + Pillow
- ffmpeg (libx264, aac)
- Noto Sans CJK KR, DejaVu Sans Mono

### 실행
```bash
python3 scripts/render.py      # → world-desk-reels-YYYYMMDD.mp4
python3 scripts/profile.py     # → profile-{a,b,c}.png
```

### render.py 구조
```
Cv 클래스        그래픽 영역 드로잉 (좌표는 1080×880 기준, K=1.09배 오버스캔 렌더)
v_*() 함수       카드별 그래픽 (캔들/라인/막대/회로도) — 뉴스마다 새로 작성하는 부분
bg_layer()       하단 솔리드 + 페이드 그라디언트
top_layer()      카테고리·진행바·수치 블록
body_layer()     헤드라인·요약·메타
encode()         rawvideo를 ffmpeg stdin으로 파이프 (중간 PNG 저장 없음)
xfade 체인       6개 세그먼트를 crossfade로 연결 + anullsrc 무음 트랙
```

### 다음 회차에 수정할 곳
1. `CARDS` 리스트 — tag / stat / h2(줄바꿈 수동 지정) / sum / date / src
2. `v_*()` 함수 — 해당 뉴스 데이터에 맞는 그래픽
3. 출력 파일명의 날짜

**헤드라인 줄바꿈은 자동 아님.** `h2=[[("텍스트", 색)], [...]]` 형태로 줄 단위 직접 지정.
한 줄 최대 폭 756px 기준 한글 약 11~12자.

## 9. Claude Code에서 이어서 작업할 때

붙여넣기용 초기 프롬프트 예시:

```
HANDOFF.md 읽고 프로젝트 파악해줘.
오늘자 해외 경제 뉴스 5건을 찾아서 scripts/render.py의 CARDS와
그래픽 함수를 갱신하고, MP4까지 렌더해줘.
규칙(표지 없음 / 자극적 기사 1번 / 안전영역 / 보도사진 미사용)은 그대로 지켜.
```

**개선 여지로 남아있는 것**
- 카드 순서 선정을 수동으로 하고 있음 → 훅 강도 기준을 명문화하면 자동화 가능
- 헤드라인 줄바꿈 수동 지정 → 폭 측정 기반 자동 분할로 대체 가능
- 프로필 이미지 최종안, 소개 문구 확정 필요
- 자체 BGM/효과음 트랙 없음 (현재 무음 AAC만 삽입, 인스타에서 음원 추가하는 방식)
