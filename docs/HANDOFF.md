# WORLD DESK — 인스타그램 릴스 경제 카드뉴스 (인수인계)

> 작성일 2026-07-23 / 채팅 세션 → Claude Code 이관용
> 이 문서 하나만 읽으면 다음 회차 제작을 그대로 이어갈 수 있게 정리함.

---

## 1. 프로젝트 개요

해외 **경제 뉴스**를 인스타그램 릴스용 세로 카드뉴스로 매일 제작한다.
채팅 세션에서 HTML 프리뷰 → Python(PIL) + ffmpeg 렌더 → MP4 파이프라인까지 구축 완료.

## 2. 확정 제작 규칙 (변경 금지 사항)

| 항목 | 규칙 |
|---|---|
| 해상도 | 1080 × 1920 (9:16) |
| 구성 | 뉴스 카드 5장 + 아웃트로 1장 = **6장** (인트로/표지 없음) |
| 길이 | 카드당 5초, 전환 크로스페이드 0.35초 → 총 28.3초 |
| 주제 | 해외 경제/시장 고정 |
| 뉴스 기준일 | **반드시 발행 당일(오늘) 날짜의 뉴스만 사용.** 어제 이전 기사·재탕 금지 |
| 날짜 표기 | `card["date"]`는 **년·월·일 모두 표기** — `YYYY년 M월 D일` (예: `2026년 7월 23일`). `YYYY.MM.DD` 식 축약 금지 |
| 카드 순서 | **가장 자극적인 기사를 1번**에 배치 (첫 3초 이탈 방어) |
| 디자인 | 전 카드 동일 템플릿 (색·폰트·레이아웃 통일) |
| 이미지 | **무료 라이선스(PD/CC0/CC BY/CC BY-SA) 실사 사진** 사용. 인물 우선(뉴스 주체 인물), 마땅한 인물이 없으면 회사 로고·마크가 보이는 건물/제품 사진으로 대체. 보도사진(로이터·AP·게티 등 wire photo)은 금지 |
| 안전영역 | 상단 160px, **하단 480px**, 우측 250px는 인스타 UI 영역 → 본문 배치 금지 |

### 저작권 관련 (중요)
릴스는 업로드 시점에 공개 배포이므로 **로이터·AP·게티 등 보도사진은 복제하지 않는다.**

이미지 소스는 위키미디어 커먼즈를 우선으로 하고, 다운로드 전에 반드시 Wikimedia API
(`action=query&prop=imageinfo&iiprop=url|size|extmetadata`)로 `LicenseShortName`과
`AttributionRequired`를 직접 조회해 확인한다 — 검색엔진 요약만 보고 판단하지 않는다.
PD/CC0는 표기 의무가 없고, CC BY/CC BY-SA는 **캡션 또는 첫 댓글에 저작자 표기가 필수**다.
사용한 사진의 출처·라이선스·저작자는 `assets/photos/CREDITS.md`에 기록한다.

인물 선정 시 해당 뉴스의 보도 현장 사진일 필요는 없다 (예: 테슬라 뉴스 → 일론 머스크 인물
사진 일반). 인물을 구하기 어려운 뉴스(지수·유가 등 추상적 수치)는 회사 로고가 보이는
건물/제품 사진으로 대체한다.

## 6. 렌더 파이프라인

### 환경 요구사항
- Python 3 + Pillow
- ffmpeg (libx264, aac)
- Noto Sans CJK KR, DejaVu Sans Mono

### 실행
```bash
python3 scripts/render.py      # → world-desk-reels-YYYYMMDD.mp4
python3 scripts/profile.py     # → profile-{a,b,c}.png
```

### render.py 구조
```
Cv 클래스        코드로 그리는 데이터 그래픽 드로잉 (좌표는 1080×880 기준, K=1.09배 오버스캔).
                 인물/건물 실사 사진을 못 구했을 때의 폴백 용도로 유지.
cover_crop()     사진을 그래픽 영역 크기로 커버-크롭 (fx,fy로 초점 위치 지정)
photo_bg()       사진을 브랜드 톤(다크 블렌드 + 상단 그라디언트 + 그레인)으로 보정
v_*() 함수       카드별 비주얼(주로 photo_bg 실사 사진, 필요 시 Cv 그래픽) — 뉴스마다 새로 작성
bg_layer()       하단 솔리드 + 페이드 그라디언트
top_layer()      카테고리·진행바·수치 블록
body_layer()     헤드라인·요약·메타
encode()         rawvideo를 ffmpeg stdin으로 파이프 (중간 PNG 저장 없음)
xfade 체인       6개 세그먼트를 crossfade로 연결 + anullsrc 무음 트랙
```

### 다음 회차에 수정할 곳
1. `CARDS` 리스트 — tag / stat / h2(줄바꿈 수동 지정) / sum / date / src
2. `v_*()` 함수 — 뉴스에 맞는 인물/건물 사진(assets/photos/에 다운로드 후 `photo_bg()` 호출)
   또는 데이터 그래픽으로 새로 작성. 사진은 `assets/photos/CREDITS.md`에 출처 기록
3. 출력 파일명의 날짜

**헤드라인 줄바꿈은 자동 아님.** `h2=[[("텍스트", 색)], [...]]` 형태로 줄 단위 직접 지정.
한 줄 최대 폭 756px 기준 한글 약 11~12자.

## 9. Claude Code에서 이어서 작업할 때

붙여넣기용 초기 프롬프트 예시:

```
HANDOFF.md 읽고 프로젝트 파악해줘.
오늘(YYYY-MM-DD) 날짜에 발행된 해외 경제 뉴스 5건만 찾아서
(어제 이전 기사는 사용 금지) scripts/render.py의 CARDS를 갱신해줘.
각 카드 그래픽은 뉴스 관련 인물(보도 현장 사진이 아니어도 됨) 무료 라이선스
사진을 우선 쓰고, 마땅한 인물이 없으면 회사 로고가 보이는 건물/제품 사진으로
대체해줘. 라이선스는 위키미디어 API로 직접 확인하고 assets/photos/CREDITS.md에
기록해줘. MP4까지 렌더해줘.
카드의 date 필드는 "YYYY년 M월 D일" 형식으로 년·월·일을 모두 표기해.
규칙(표지 없음 / 자극적 기사 1번 / 안전영역 / 보도사진 미사용)은 그대로 지켜.
```

**개선 여지로 남아있는 것**
- 카드 순서 선정을 수동으로 하고 있음 → 훅 강도 기준을 명문화하면 자동화 가능
- 헤드라인 줄바꿈 수동 지정 → 폭 측정 기반 자동 분할로 대체 가능
- 프로필 이미지 최종안, 소개 문구 확정 필요
- 자체 BGM/효과음 트랙 없음 (현재 무음 AAC만 삽입, 인스타에서 음원 추가하는 방식)
